# しごと、つなぐ。名古屋

名古屋の企業と就労支援事業所をつなぐマッチング Web アプリです。公益社団法人名古屋青年会議所 多彩な人財活躍委員会の事業「イロトリドリ〜多彩な人財と企業がともに生み出す、活躍と新たな価値〜」（事業議案 104-04K-X427K）のファンクション1（参加者の募集）とファンクション3（伴走型マッチング）で使います。

- PC・スマホのブラウザで動き、スマホではホーム画面に追加してアプリとして使えます（PWA）
- 費用は0円：配信は GitHub Pages、データの保存は Firebase の無料プラン（Spark）

## 画面

| 画面 | 使う人 | できること |
| --- | --- | --- |
| はじめに | 誰でも | 事業の説明、セミナー案内、ホーム画面への追加 |
| 企業の方 | 企業 | 業務の相談・セミナー申込を送る |
| 事業所の方 | 就労支援事業所 | 事業所を登録する |
| マッチング | 委員会 | 企業ごとに、合いそうな事業所を点数つきで見る。伴走ペアを作る |
| 伴走記録 | 委員会 | ペアごとに5ステップの進み具合・担当・メモ・雇用契約を記録。KDI を確認 |
| 登録一覧 | 委員会 | 届いた企業・事業所の登録を探す・直す・削除する |

委員会用の画面は、Google でログインし、管理者に登録されたアカウントだけが見られます。

## 公開までの手順（初回だけ）

### 1. GitHub Pages で公開する
1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Build and deployment** の Source を「Deploy from a branch」、Branch を `main` ／ `/ (root)` にして Save
3. 数分後、`https://<ユーザー名>.github.io/shigoto-tsunagu/` で開けるようになる

この時点では「お試しモード」で、送信内容はその端末にだけ保存されます。

### 2. Firebase（データの保存先）を作る
JC の活動用の Google アカウントで行ってください。クレジットカードの登録は不要です（Spark プランのまま使う）。

1. https://console.firebase.google.com/ で「プロジェクトを作成」。名前は `shigoto-tsunagu` など。Google アナリティクスはオフでよい
2. 左メニュー **構築 → Firestore Database → データベースを作成**。ロケーションは `asia-northeast1`（東京）、「本番環境モード」で開始
3. Firestore の **ルール** タブを開き、このリポジトリの `firestore.rules` の中身を全部貼り付けて「公開」
4. **構築 → Authentication → 始める → Sign-in method** で「Google」を有効にする
5. Authentication の **設定 → 承認済みドメイン** に `<ユーザー名>.github.io` を追加
6. **プロジェクトの設定（歯車）→ マイアプリ → ウェブ（</>）** でアプリを登録し、表示された `firebaseConfig` の値を `config.js` に貼り付けて保存（apiKey は公開してよい値です。データはルールで守られます）

### 3. 委員会メンバー（管理者）を登録する
1. Firestore の **データ** タブで「コレクションを開始」→ コレクション ID に `admins`
2. ドキュメント ID に、管理者の Google アカウントのメールアドレスを**小文字で**入れる（例：`taro.jc@gmail.com`）。フィールドは `name`（文字列、氏名）など何か1つあればよい
3. 人を追加するときは、同じように `admins` にドキュメントを追加する

### 4. 動作確認
1. 公開した URL を開き、「企業の方」から試しに送信する
2. 「マッチング」で Google ログイン → 送信した内容が出れば完了
3. 試しのデータは Firestore の画面から削除する

## 無料プランの範囲
Firebase Spark プランは、1日あたり読み取り5万回・書き込み2万回・保存1GBまで無料です。この事業（企業20社・ペア15組程度）なら十分におさまります。上限を超えた場合は課金されずに止まるだけです（カード未登録のため）。

## Google Play で配布したくなったら
このアプリはそのまま Google Play 用に包めます（PWABuilder や Bubblewrap で TWA 化）。ただし Google Play の開発者登録料 25ドル（1回のみ）が必要で、個人の新規アカウントは「12人以上のテスターで14日間のクローズドテスト」が公開の条件です。

## ファイル構成
- `index.html` / `style.css` / `app.js` … アプリ本体
- `config.js` … Firebase の設定（ここだけ書き換える）
- `firestore.rules` … データベースの読み書きルール
- `manifest.webmanifest` / `sw.js` / `icons/` … ホーム画面に追加するための設定
- `privacy.html` … 個人情報の取り扱い
